# 3D Platformer

A simple 3D platformer prototype created as a learning project in Unreal Engine 5.  
Initially started during the **Foxminded** Unreal Engine course, this project evolved into a small sandbox for experimenting with gameplay mechanics and testing new ideas.

## 🎮 Overview
At its core, this is a basic 3D platformer focused on character movement and respawn logic.  
The goal is to gradually turn it into a flexible testbed for experimenting with mechanics such as collectibles, checkpoints, and level progression.

## 🧱 Current Features
- Third-person character movement  
  - walk, run, jump
- Checkpoint & respawn system  
- Advanced life system  
  - multiple lives  
  - respawn at checkpoints  
  - full level restart when lives run out  
- Moving platforms  
  - point-to-point platforms  
  - spline-based platforms  
- Traps
- Collectibles  
- Interaction system

## 🚧 Planned Features

## 🕹️ Controls
- **Move** — WASD
- **Jump** — Space  
- **Sprint** — Left Shift
- **Interact** — E 

## 🧩 How to Run
1. Clone the repository  
2. Open the `.uproject` file in **Unreal Engine 5.4** (or newer)  
3. Load the test level  
4. Press **Play** to start

## 🧠 Purpose
This is not a commercial project — it's a **sandbox for learning and experimenting** with C++ and Unreal Engine.  
The main focus is gameplay programming, logic structure, and engine systems exploration.
